О приложении

Веб-приложение «Парковка» предназначено для учета автомобилей, находящихся на парковке, и справочника моделей автомобилей с их стоимостью. Можно добавлять, изменять и удалять записи, а также рассчитать стоимость стоянки и примерную текущую стоимость автомобиля.

Роли пользователей
  • READ_ONLY - только просмотр (назначается при регистрации);
  • USER - видит и редактирует только записи, которые создал сам;
  • ADMIN - полный доступ ко всем данным и назначение ролей.
Технологии

Java 17, Spring Boot 3, Spring MVC, Spring Security, Spring Data JPA (Hibernate), H2, Thymeleaf, Bootstrap 5, Lombok, Spring Boot Actuator.
